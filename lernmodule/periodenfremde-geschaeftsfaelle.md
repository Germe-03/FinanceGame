# Periodenfremde Geschäftsfälle

## Was sind periodenfremde Geschäftsfälle?

Aufwände oder Erträge, die **nicht zum laufenden Geschäftsjahr** gehören, sondern einer früheren oder späteren Periode zuzuordnen sind.

## Arten

### Periodenfremder Aufwand

Betrifft eine **vergangene** Periode — z. B. Nachzahlung von Steuern für das Vorjahr.

`Ausserordentlicher Aufwand (8000) / Bank`

### Periodenfremder Ertrag

Betrifft eine **vergangene** Periode — z. B. Rückerstattung einer zu hoch bezahlten Versicherungsprämie aus dem Vorjahr.

`Bank / Ausserordentlicher Ertrag (8100)`

## Abgrenzung

| | Rechnungsabgrenzung | Periodenfremder GF |
|---|---|---|
| Zeitpunkt | Am Jahresende | Im laufenden Jahr |
| Zweck | Zukunft abgrenzen | Vergangenheit korrigieren |
| Konto | ARA / PRA | Ausserordentl. Aufwand/Ertrag |

## Ausweis in der Erfolgsrechnung

Periodenfremde Geschäftsfälle werden im **ausserordentlichen Ergebnis** (Kontengruppe 8) ausgewiesen, damit das ordentliche Betriebsergebnis nicht verzerrt wird.
